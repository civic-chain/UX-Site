## Цели

- Инфра Claude Code работает корректно по актуальной документации, не по встроенной памяти модели.
- `AGENTS.md` и `CLAUDE.md` без дублей; AGENTS импортирован в CLAUDE через `@AGENTS.md`.
- Минимум хуков и кастомных команд — без преждевременной автоматизации.

## Перед Правкой Инфраструктуры

- Перед правкой Claude-Code-инфры — сверить с `code.claude.com`. Встроенная память может быть устаревшей.
- Подтверждено сейчас: `AGENTS.md` не загружается автоматически (нужен `@AGENTS.md`-импорт), permissions `Bash(npm run *)` с пробелом, UserPromptSubmit hook без inner-обёртки и без matcher.

## Структура Файлов

- `AGENTS.md` = общий контракт всех агентов. НЕ загружается Claude Code автоматически — нужен `@AGENTS.md` импорт в `CLAUDE.md`.
- `CLAUDE.md` = тонкая Claude-Code-операционка. Загружается каждой сессией. Лимит около 200 строк.
- `_ops/criteria/*.md` = правила по доменам. Источник правды для правил поведения.
- `_ops/PROJECT-ROADMAP.md` = цель + стадии.
- Один файл — одна роль. Дубли вычищать.

## Ссылки Вместо Inline Дублирования

- В инструкционных поверхностях (`AGENTS.md`, `CLAUDE.md`, папочные инструкции, `.claude/rules/`) ссылаться на `_ops/criteria/*.md`, не дублировать содержимое. Пример: «*неприкосновенные tokens — `landing-design-and-brand.md`*», не полный список.
- Краткий перечень (4-5 заголовков/якорей) допустим. Полные правила — только в criteria/.

## Hooks

- Минимум хуков на уровне проекта. Дисциплина criteria-anchor приходит из глобального Claude-конфига пользователя — не дублировать здесь.
- Новые project-level хуки — только по явному запросу пользователя.

## Кастомные Команды И Subagent'ы

`.claude/commands/`, `.claude/agents/` — создавать после **3+ ручных повторений** одного паттерна. Сейчас 0 — не создавать.
