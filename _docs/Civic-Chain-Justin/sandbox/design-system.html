Scope · single

The <ExpandableScope> wrapper turns a card set into an accordion so only one item stays open at a time. Used in the FAQ.

Why start with small-town municipalities?

That is where the pain is concentrated: lean teams, real contract spend, and visible public accountability. The pilot fits the product quickly.

So is this basically a blockchain company?

No. First it is a municipal contracts and accountability platform. The ledger is trust infrastructure, not the first thing a visitor needs to understand.

Is public input required for every contract?

No. It is an optional layer that can be added where it is genuinely useful, instead of forcing every contract into a public vote.

VideoSurface

An RSC-friendly wrapper for <video>. Aspect ratio, overflow, and radius come built in. Use it with a poster frame for the reduced-motion fallback.

Component: <VideoSurface src={...} aspect="hero" poster={...} />

A live demo will appear once the project has video content. For now, use sandbox/hero as the preview surface.

Motion Canon

CSS-based motion with no JavaScript animation libraries. Three easing curves plus four durations make up the full vocabulary. View Transitions are reserved for stateful route changes.

--ease-softcubic-bezier(0.2, 0.8, 0.2, 1)Default for most transitions
--ease-standardcubic-bezier(0.4, 0, 0.2, 1)Material-style deceleration
--ease-motion-incubic-bezier(0.0, 0.0, 0.2, 1)Enter animations
--dur-fast180msHover, focus, micro-feedback
--dur-med320msExpandable reveal, tooltip
--dur-slow420msScroll-reveal, section entrance
--dur-xslow600msFull-page transitions, hero entrance

Scroll Reveal

Pure CSS scroll-driven animation. Sections with data-scroll-reveal="true" fade in as they enter the viewport. The hero is excluded because it is already visible on load. Under prefers-reduced-motion: reduce the animation turns off.

A live example is on the home page. The `problem`, `howItWorks`, `numbers`, `workflowTools`, and `trust` sections use scroll reveal.

Reduced Motion

All motion primitives include an @media (prefers-reduced-motion: reduce) fallback. `Expandable`, `scroll-reveal`, and `video-surface` all disable animation. Sections with data-disable-motion="true" disable everything: `animation`, `transition`, and `transform`.
