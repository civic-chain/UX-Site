# Contact Build Map

## Meaning

One cohesive path toward a pilot conversation: short top screen, then explanation of the path and a strong email card. The page should not read as separate slabs.

## Desktop

- Overall assembly: vertical page stack; top screen above, main block directly below, without a large gap.
- Top screen: left text block with small label, heading, subtitle, and secondary back link if it remains on the live page.
- Main block: wide two-column grid. Left column about 60% for explanation and route; right column about 40% for the email card. A thin vertical divider may sit between them.
- Left column: vertical flex, with elements moving top to bottom. First heading and paragraph, then horizontal route line.
- Route line: three equal steps in one line; the line, dots, numbers, and labels are code. On desktop this should read as a path, not three separate cards.
- Right column: email card as vertical flex - email/icon, heading, short rule, text, large email button, privacy note.

## Mobile

- Everything becomes one column: top screen, explanation, steps, email card.
- Horizontal route line collapses into a vertical step list or short left rail; each step's text stays live.
- Email card follows the steps, button uses a comfortable width, and illustration moves into the lower layer without covering the button.

## Illustration

- `town-courthouse-landscape.webp` - lower background inside the email card, pinned to the bottom and stretched like a soft town strip.
- Asset must be dense and opaque; muting is done with layout opacity.
- On mobile, illustration sits lower and smaller: the town silhouette stays visible, but the email button remains the main action.

## Code / Icons

- Star in the label, route icons, route line, dots, email icon, privacy mark, buttons, borders, shadows, spacing.
- Do not bake text, email, step labels, or call to action into an image.

## Do Not Copy

- Full generated render as a layout image.
- Generated text if it is not on the live page.
- Route line, email button, icons, or labels as images.
